# Stylized MOBA production set

Final production pass using a clean, hand-painted fantasy MOBA visual language. Character bodies use relaxed A-pose sheets split into front/back and left/right views. Weapons, shields, robes, and lower-body garments that would interfere with rigging are supplied as separate props.

## Production notes

- Body sheets use relaxed A-pose with arms angled down approximately 35–45 degrees.
- Side views keep the near arm readable and avoid forward/back arm swing.
- Orryx's shield is a separate prop.
- Elowen's long robe is separate from the base body.
- Kaelor's lower-body cloth and trousers are one removable garment module.
- Rendering avoids photorealistic PBR and dense sci-fi greebles in favor of readable hand-painted MOBA forms.
